# Dynastinae

## Overview

Dynastinae is a variant of Scarab featuring **thumb support** designed for right-handed players. 


### Assembly Variants

- **Right-Handed Default**: As shown in the STL files
- **Left-Handed Configuration**: Mirror the body assembly components (swap left/right panels)

## Setup Notes

> *Ensure you have the correct STL files for your handedness before assembling. Left-handed users should swap the body panel components to mirror the right-hand default configuration.*
