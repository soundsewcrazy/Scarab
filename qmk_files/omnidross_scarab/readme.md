## Overview

Scarab is a custom all-in-one gaming and productivity input device that combines the functionality of a keyboard and trackball into a single package. It's designed with changes and features that make it particularly suitable for gaming, representing a shift away from typical custom keyboard/trackball setups that emphasize coding and software development.

**Ideal Users:**
- Gamers seeking an "fight stick" experience for all game types
- Players of input-intensive games like RTS, MOBAs, and FPS titles
- Users who want consistent input control whether at their desk or on the couch

Having both mouse and keyboard inputs in one device makes gameplay much more feasible across different environments.

## Installation & Setup

### Prerequisites

- **QMK** is required to flash precompiled hex files or compile firmware from uncompiled source
- Access to the QMK repository listed above for all necessary files

### Getting Started

1. Download the project from [GitHub](https://github.com/soundsewcrazy/Scarab)
2. Install and configure QMK software
3. Use precompiled HEX files included in the repository, or compile firmware directly from source

> **Note:** Initial releases may require some detective work to understand, implement, or modify keymaps and code configurations.

## Configuration

### Default Keybindings

Keybindings are defined in the `keymaps` folder. To change keybindings:

1. Edit the appropriate keymap file(s)
2. Re-compile the firmware using QMK

The default configuration is designed for gaming but can be customized to suit your needs.
